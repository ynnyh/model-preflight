执行 model-router 航后检查（详见 `~/.zcode/skills/model-router/SKILL.md` 航后检查一节）：

1. 看未提交的工作区改动：`git status` + `git diff --stat`；工作区干净时先问我看最近一次提交（`git diff HEAD~1`）还是指定范围，不猜。
2. diff ≤ 约 200 行 → 完整展示；更大 → 只给 `--stat` 账单 + 文件清单，问我要细看哪个文件。
3. 用当前会话模型直接叙述，汇报三件事：改动范围、与任务的对应关系、值得注意的点。**不调用 Jev 或任何额外模型**。
4. 非 git 目录 → 明说，退化为按修改时间列出最近改动的文件。
